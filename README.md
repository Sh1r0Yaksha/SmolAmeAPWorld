# Smol Ame APWorld

This project integrates Smol Ame with Archipelago, a multi-game randomizer framework that shuffles items across locations to create a unique gameplay experience.

## Installation

The APWorld is available on the [Releases](https://github.com/Sh1r0Yaksha/SmolAmeAPWorld/releases) page. For further information, take a look at [Setup.md](/src/docs/setup_en.md)
