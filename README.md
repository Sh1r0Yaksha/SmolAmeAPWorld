# Smol Ame APWorld

This project integrates Smol Ame with Archipelago, a multi-game randomizer framework that shuffles items across locations to create a unique gameplay experience.

## Installation

This is still a Work in Progress, once complete it will be available on the [Releases](https://github.com/Sh1r0Yaksha/SmolAmeAPWorld/releases) page

## Contributions

Refer to the [APQuest World](https://github.com/ArchipelagoMW/Archipelago/tree/main/worlds/apquest) repository for documentation. This project uses it as a template to build upon.

For level, item, and location names, refer to the initial entries in area_items.json. The naming structure should follow the format used in the JSON file:
```
{
    region_name: {
        item_name: location_name
    }
}
```
